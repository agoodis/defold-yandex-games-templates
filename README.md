# Defold Yandex Games Templates

Готовые стартовые шаблоны Defold для публикации игр на Yandex Games.

## Yandex Games

Пустой 2D-проект с разрешением 1920×1080, HTML5-настройками, Yandex Games SDK
и типовыми библиотеками Insality.

## Yandex Games 3D

3D-проект с камерой, кубом, сферами, плоскостью, освещением, 3D-физикой,
Yandex Games SDK и тем же набором типовых библиотек.

Архивы для установки через окно `New Project` находятся в релизе `v1.0.0`.
