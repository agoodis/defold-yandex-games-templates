# Yandex Games 3D

Стартовый 3D-шаблон Defold для проектов под Yandex Games.

В проекте уже есть:

- перспективная камера;
- куб, две сферы и плоскость;
- простое направленное освещение;
- вращение куба и управление светом мышью или касанием;
- физика типа `3D`;
- `defold-yagames`;
- Druid, Event, Saver, Log, Lang, Tweener, Quest и Token.

После создания проекта выберите `Project -> Fetch Libraries`.
