# Yandex Games

Стартовый шаблон Defold для проектов под Yandex Games.

В `game.project` уже подключены:

- defold-yagames
- Druid
- Event
- Saver
- Log
- Lang
- Tweener
- Quest
- Token

После создания проекта выберите `Project -> Fetch Libraries`.

Версии зависимостей зафиксированы, чтобы обновления библиотек не ломали новые
проекты неожиданно.
